# 常见误判与排查陷阱

本文件记录实际排查中走过的弯路，避免重复。

## 1. "图片旁边有正方形"——不是文档内容

**现象**：用户反馈图片旁、图注前有黑色 ■ 方块，要求删除。

**错误判断**：以为是书签标记 → 把所有书签改成 `_` 前缀。改完用户截图显示方块仍在。

**真相**：这些方块来自 Word / 本地编辑器的「**显示/隐藏格式标记**」功能。开启后 Word 会给**图片锚点**、**图注段落**渲染 ■ 与 "Γ+L" 形标记。这是编辑器可视化效果，不写入 docx。

**排查方法（穷举法，按序执行）**：

1. `document.xml` 中 `■`(U+25A0) / `□`(U+25A1) / `▪`(U+25AA) 计数 → 0
2. 几何符号区段 `0x2580–0x25FF` 全字符扫描 → 0
3. `w:sym` / `w:rect` / `v:rect` / `w:pict` / `w:object` / `w:sdt` / `w:AlternateContent` / `fldSimple` / `instrText` / `commentReference` / `w:ins` / `w:del` 计数 → 0
4. 每个 `w:drawing` 的类型：是 `pic:pic`（图片）还是 `wps:wsp`（形状）/ `wpg:wgp`（组合）
5. 嵌入图片本体（`word/media/*`）用图像工具目视检查 + 采样边角像素
6. styles.xml 的 `numPr` / numbering.xml 的 `lvlText` 是否含方块项目符号（`Symbol` 字体的 `\uf0b7` 是圆点，不是方块）
7. 同目录其它 docx 是否也有 ■（若都没有，说明与文件无关）

**结论与处置**：告诉用户按 `Ctrl+Shift+8`（Mac `⌘+8`）关闭格式标记，或点工具栏 `¶` 按钮。不要为了"删方块"去改文档——文件本来就是干净的。

**教训**：用户说"删掉 X"时，先确认 X 是否真的存在于文件中，再动手。凭猜测改文档既无效又损害信任。

## 2. 后缀字母"看起来像链接但点不动"

**现象**：`Fig. 4A` 中的 `A` 是蓝色，点击无反应，颜色也与正文不一致。

**根因**：`A` 是段落的直接子级 `w:r`（不在 `w:hyperlink` 内），但被单独设置了 `w:color=1F4E79`。这是早前做链接时把颜色写到了链接外的 run 上。

**排查**：遍历段落**直接子级** `w:r`（`p.findall(qn('w:r'))`，不要用 `.//`），检查 `w:rPr/w:color/@w:val == 1F4E79`。凡是不在 `w:hyperlink` 内的都属此类。

**修复**：`format_fix.py --fix-suffix-color`（删掉 color-only 的 `w:rPr`）。

## 3. 图引用编号指错图

**现象**：正文写 "…detected … by XRD in Fig. 4"，但 XRD 数据实际在 Fig. 3。

**处置**：改显示文字的同时**必须改锚点**。只改文字会得到"写着 Fig. 3、点进去却是 Fig. 4"的错链接。

```python
h.set(qn('w:anchor'), '_fig_3')          # 改锚点
for t in h.findall('.//' + qn('w:t')):   # 改文字
    t.text = 'Fig. 3'
```

**定位方法**：先按段落文本内容（如 `XRD in`）锁定段落，再在该段落内按锚点名 + 链接文字双条件匹配，避免误改同文档其它 11 处指向同一图的链接。

## 4. 段落替换后出现 `Fig. 217171819Fig. 4…` 乱码

见 `ooxml-recipes.md` §4。根因是只删 `w:r` 不删 `w:hyperlink`，旧超链接文字残留段尾。

## 5. 编辑器预览与实际文件不一致

**现象**：改完磁盘文件，用户预览里还是旧内容；或用户一保存，改动没了。

**根因**：文档在本地编辑器中有内存副本，与磁盘文件相互独立。

**正确顺序**：python-docx 改磁盘 → `open_file open_with_existing=true` 重载 → `get_pool_status` 取新 `file_id` → 查询工具复核 → **不要**再 `save_file`。

## 6. 审计脚本的假阳性

初版 `format_audit.py` 会把两类正常内容报成问题：

- **图注/表注段落**（`Fig. 1. (A) South façade…`）：标签开头 + 句点，是 caption 不是引用，本就不该有链接。
- **参考文献条目**（`[1]E. Sebastián Pardo…`）：在 References 标题之后的条目编号，不是正文引用。

处置：识别 References 标题段索引，其后段落跳过引用检查；用 `^(Fig\.|Table)\s*\d+\s*\.` 识别 caption 并跳过。修正后标准稿 0 问题、原始稿 41 问题，区分度正确。
